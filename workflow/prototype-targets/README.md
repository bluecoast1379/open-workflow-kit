# Editable prototype targets

HTML remains the default prototype. `/02D-可编辑原型交付` is explicit and optional.

- Figma: offline headless development-plugin bundle, imported locally by the user.
- Sketch: deterministic ZIP-based `.sketch` document generated directly from the model.
- Axure: official Figma bridge handoff only; no native `.rp` claim.

Every target writes a machine report and a human handoff. Structural validation never substitutes for real-client edit/save/reopen evidence.
