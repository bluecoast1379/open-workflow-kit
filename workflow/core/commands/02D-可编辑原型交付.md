# /02D-可编辑原型交付

## Goal

从 `/02C-HTML原型` 的 canonical prototype model 按需生成 Figma local plugin、Sketch `.sketch` 或 Axure Figma bridge 本地交付；默认 HTML 路径不变，未显式选择 target 时不执行本阶段。

## Required Inputs

- `AGENTS.md`
- `workflow/team-profile.yaml`
- `features/{feature}/02-产品文档.md` 与适用的 `02B-UI设计.md`
- `features/{feature}/completion/contract.yaml`（Completion Contract）
- `features/{feature}/prototype/model.json`
- `features/{feature}/prototype/provenance.json`
- `workflow/prototype-targets/support-matrix.yaml`

## Execution Rules

- target 只允许 `figma`、`sketch`、`axure`，禁止根据本机软件、账号或历史使用记录推断。
- Figma 与 Sketch 直接消费同一 model；Axure 必须引用同 model hash、client evidence 非 STALE 的 Figma run。
- 所有输出限制在 `features/{feature}/prototype/exports/{target}/`；拒绝路径穿越与 symlink 越界。
- 默认不联网、不写 Figma/Axure Cloud、不发布 plugin、不写远程 Git；外部写入必须进入 `AWAITING_EXTERNAL_AUTHORIZATION`。
- 自动结构 PASS 只证明产物结构；真实客户端未完成 edit/save/reopen 前 capability 保持 `NOT_VERIFIED`。
- 页面、可见文本、主要组件和属性必须分别满足 mapped+loss+unknown=total；任一 unknown 大于 0 阻断 PASS。
- Figma local plugin ID 只能来自 ignored local config；不得进入受版本控制的 core/template/report。

## Required Structure

```text
features/{feature}/prototype/exports/{target}/
├── current.json
├── latest-attempt.json
├── attempts/{attempt_id}.json
└── runs/{run_id}/
    ├── manifest.json
    ├── report.json
    ├── README.md
    └── target-specific artifacts
```

- `run_id=sha256(model_hash + NUL + exporter_version + NUL + target_config_hash)`；run 不可变，attempt 只追加。
- report 分别记录 generation、structural validation、client validation、execution 与 capability。
- Figma 在 current PageNode 创建一个 versioned root Frame；产品 pages 是 direct-child Frames，`createPage` 调用数为 0。
- Sketch archive 使用固定 entry 顺序、timestamp、STORE、CRC32 与 source ID 派生 UUID。
- Axure 只生成 `BRIDGE_ONLY` handoff，`native_rp=false`，capability ceiling=`DEGRADED`。

## Exit Criteria

- target artifact、manifest、report 与≤8 步 README 已生成，或以确定 reason code 记录 BLOCKED/FAIL attempt。
- entity/property coverage 守恒且 unknown=0；失败不改变 HTML 或 previous current。
- 真实客户端未验证时明确为 NOT_VERIFIED；不得把 mock、schema 或 archive PASS 升格为 client PASS。
- 更新 `features/{feature}/00-工作流状态.md`，但只有 `/07-测试执行` 或 `deliver-until-done` 可翻转 Completion Contract Oracle。

## Required Outputs

- `features/{feature}/prototype/exports/{target}/attempts/{attempt_id}.json`
- 成功时：immutable `runs/{run_id}/`、`current.json`、`latest-attempt.json`
- 阻塞/失败时：`latest-attempt.json`、精确 reason code 与恢复步骤；previous current 保持不变
